# Credits

## Original concept and development

Marco Iannacone — [pippo.com](https://pippo.com/)

JOSHUA Terminal began as an Easter egg inside pippo.com's own terminal-style personal site, and is published here as a standalone application.

## Inspiration

Inspired by *WarGames* (1983) and its fictional WOPR/JOSHUA computer. See [TRIBUTE.md](TRIBUTE.md).

## Contributors

Future contributors are credited through the project's Git history. This file does not yet list individual contributor names beyond the original author; a `CONTRIBUTORS.md` may be added later if the project settles on that as the right place for it.

## Technology

Built entirely with standard browser technology, no frameworks or runtime dependencies:

- HTML
- CSS
- JavaScript
- Web Speech API (spoken narration)
- Web Audio API (synthesized sound effects)
- SVG (the world map)
